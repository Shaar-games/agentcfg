---
name: documentation-check
description: Check current official documentation when a coding task depends on a library API, configuration format, or protocol requirement.
---

Identify the library or protocol and the version relevant to the task.
Read its official documentation using the tools available in the active harness.
Check example signatures and configuration keys against that version.
Explain material differences from the existing code and cite the sources used.
Report when a source is unavailable rather than inventing an API.

This example does not install packages or modify configuration automatically.
